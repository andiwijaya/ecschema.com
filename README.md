# ECSchema

ECSchema is a fast, bilingual foundation for learning electronics through a structured competency path.

## Routes

- `/en/` — English homepage
- `/id/` — Bahasa Indonesia homepage

## Structure

The site is intentionally static and content-first. The homepage establishes the ECSchema visual language, competency progression, project mapping, responsive layout, language switching, SEO metadata, sitemap, robots policy, and supplied brand artwork.

## Local preview

Serve the repository root with any static file server. The deployable output is in `dist/`.

## Repository

Production source: https://github.com/andiwijaya/ecschema.com

Cloudflare Pages deploys the `main` branch automatically.
